# TMOS v0.2 API Documentation

Status: Released
Version: 0.2.0
Date: 2026-07-17
Base path: `/api/v1`

## 1. API Principles

- All production endpoints are versioned under `/api/v1`.
- Protected endpoints require Bearer access token.
- Authorization is permission-based and centrally enforced.
- Unmapped protected routes are denied by default.

## 2. Response Envelope

Success:

```json
{
  "success": true,
  "data": {},
  "meta": {
    "correlationId": "...",
    "timestamp": "..."
  }
}
```

Error:

```json
{
  "success": false,
  "error": {
    "code": "RBAC_DENIED",
    "message": "Insufficient permissions",
    "details": {}
  },
  "meta": {
    "correlationId": "...",
    "timestamp": "..."
  }
}
```

## 7. Authorization Errors

- `401 AUTH_FORBIDDEN`
  - Missing/invalid/expired token.
- `403 RBAC_DENIED`
  - Authenticated but not authorized.
  - Also returned for unmapped protected routes (deny-by-default).

## 8. Correlation IDs

- Client can pass `x-correlation-id`.
- If omitted, server generates one.
- Correlation ID is propagated in API response and audit logs.
