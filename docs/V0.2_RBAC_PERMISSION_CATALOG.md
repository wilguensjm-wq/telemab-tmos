# TMOS v0.2 RBAC Permission Catalog

Status: Released
Version: 0.2.0
Date: 2026-07-17

## 1. Roles

- Administrator
  - Full access via wildcard permission `*`.
- Operator
  - Operational read/write permissions.
- Viewer
  - Read-only operational permissions.

## 4. Route Mapping and Policy

- Every protected route requires an explicit permission mapping.
- Startup fails if any protected route is unmapped.
- Unmapped protected requests are denied by default (`403 RBAC_DENIED`).
- Authorization decisions are audited as `authz.decision` records.
