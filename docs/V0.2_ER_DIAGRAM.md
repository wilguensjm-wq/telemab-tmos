# TMOS v0.2 ER Diagram

Status: Released
Version: 0.2.0
Date: 2026-07-17

## ER Model (Phase 1 + RBAC)

```mermaid
erDiagram
  users ||--o{ sessions : has
  users ||--o{ user_roles : assigned
  roles ||--o{ user_roles : grants
  roles ||--o{ role_permissions : includes
  permissions ||--o{ role_permissions : maps

  users {
    text id PK
    text username UK
    text password_hash
    text display_name
    text role_name
    boolean is_active
    timestamptz created_at
    timestamptz updated_at
  }

  sessions {
    text id PK
    text user_id FK
    text refresh_token_hash
    timestamptz created_at
    timestamptz expires_at
    timestamptz revoked_at
  }

  roles {
    text role_key PK
    text description
  }

  permissions {
    text permission_key PK
    text description
  }

  role_permissions {
    text role_key PK,FK
    text permission_key PK,FK
  }

  user_roles {
    text user_id PK,FK
    text role_key PK,FK
    timestamptz assigned_at
  }

  config_entries {
    text config_key PK
    jsonb value_json
    timestamptz updated_at
  }

  events {
    text id PK
    timestamptz timestamp
    text provider
    text resource
    text action
    text severity
    text status
    text operator
    text correlation_id
    jsonb metadata
  }

  audit_logs {
    text id PK
    timestamptz timestamp
    text actor
    text action
    text target
    text result
    text provider
    text correlation_id
    text network_path
    jsonb metadata
  }

  provider_state {
    text provider_key PK
    text status
    jsonb payload
    text correlation_id
    timestamptz updated_at
  }
```

## Notes

- `users.role_name` is retained for compatibility.
- Effective authorization is resolved from RBAC tables (`user_roles`, `role_permissions`, `permissions`, `roles`).
- `audit_logs` captures `authz.decision` events with permission context.
